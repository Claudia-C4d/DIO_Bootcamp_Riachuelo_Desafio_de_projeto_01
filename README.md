# DIO_Bootcamp_Riachuelo_Desafio_de_projeto_01
Projeto Bootcamp DIO/Riachuelo de App de Organização de Finanças Pessoais com Vibe Coding

Esse projeto conta com 02 arquivos:

Bootcamp_DIO_Riachuelo_PRD_App_Cents_Count_s.pdf;  
Bootcamp_DIO_Riachuelo_Desafio_de_Projeto_01.pdf;

Os documentos apresentam o PRD (Product Requirements Document) para um aplicativo para Organização de finanças pessoais, o CENTS COUNT_S, criado com o auxílio do Microsoft Copilot e uma breve ilustração do desenvolvimento do projeto, gerado através de interações com o Lovable. 

Esse material se refere à um projeto final do Bootcamp DIO - Riachuelo para a criação de produtos com IA, quando durante o curso tive a oportunidade de conhecer ferramentas como o N8N para automação de fluxos e o Lovable, na criação de aplicativos (ainda em teste), o que tem sido uma experiência enriquecedora.
